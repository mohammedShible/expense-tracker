Expense Tracker

A responsive personal expense tracker built with HTML, CSS, and JavaScript. It allows users to manage their expenses, monitor spending habits, and visualize financial data through interactive charts.

Overview

Expense Tracker is a front-end web application designed to make expense management simple and organized. Users can add, edit, delete, and track their expenses while viewing useful statistics and visual summaries.

The application uses the browser's Local Storage to persist data, so expenses remain available even after refreshing the page.

Features

- Expense Management (CRUD): Add, edit, and delete expenses.
- Data Persistence: Save expenses using Local Storage.
- Expense Statistics: View spending summaries and calculated statistics.
- Data Visualization: Display expense information using interactive charts.
- Dark Mode: Switch between light and dark themes.
- Form Validation: Validate user input before saving expenses.
- Interactive UI: Dropdown menus, modal dialogs, and event-driven interactions.
- Responsive Design: Adapt to different screen sizes and devices.

Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Chart.js
- Local Storage API
- Font Awesome

Getting Started

Installation

1. Clone the repository:
   
   git clone https://github.com/mohammedShible/expense-tracker.git

2. Navigate to the project directory:
   
   cd expense-tracker

3. Open "index.html" in your browser.

No additional installation or build tools are required.
